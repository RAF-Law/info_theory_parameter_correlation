# Parameter Correlation Analysis
This is a summer research internship project under professor Ankush Aggarwal's supervision. The project itself assists with Shiting Huang's P.h.D project in the University of Glasgow.

## Dependencies
MatplotLib [https://matplotlib.org/stable/users/index.html]
NPEET [https://github.com/gregversteeg/NPEET](https://github.com/gregversteeg/NPEET)_(package contained in the repo)
Scikit-learn [https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html]
Numpy
  
## Running
Clone from git repository:

    git clone https://github.com/RAF-Law/info_theory_parameter_correlation

Run jupyter notebook from command line and navigate to the folder, open .ipynb file.
